## Project Summary

Rydora is a web-based tricycle booking system designed to provide passengers with a more convenient and organized way of requesting tricycle rides. Passengers can submit booking requests by providing their pickup and destination locations. The system also provides booking information and status to help passengers monitor their rides. Drivers and administrators can manage booking requests, driver information, and ride records.
